# GStack For Hermes

## Procedure
1. Define the wedge: smallest useful outcome that changes the situation.
2. Name constraints, non-goals, and failure modes.
3. Choose the worker lane that owns the next proof-bearing action.
4. Require verification for claims and greenlight for irreversible actions.
5. Preserve the result as a brief, checkpoint, or durable note when useful.
