# Researcher Quick

Use this mode for normal research.

## Steps
1. Clarify the decision or question being answered.
2. Gather local context first, then external evidence when the answer may be stale or source-sensitive.
3. Provide a concise recommendation with source trail and uncertainty.
4. Do not start iterative optimization loops in this mode.
