# Listing Manager Core

## Procedure
1. Start from an approved offer or clearly mark the listing as draft.
2. Write for the buyer problem, not generic AI hype.
3. Include deliverables, examples, requirements, price bands, timeline assumptions, and FAQ.
4. Avoid unverified ROI, guaranteed outcomes, fake urgency, or unsupported credentials.
5. Output publish-ready draft plus approval checklist.
