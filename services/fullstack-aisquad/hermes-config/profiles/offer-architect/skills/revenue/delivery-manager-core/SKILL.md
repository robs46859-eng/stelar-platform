# Delivery Manager Core

## Procedure
1. Confirm signed/approved scope before treating work as won.
2. Create milestone plan, inputs needed, risks, acceptance tests, and communication cadence.
3. Assign technical tasks to Solution Builder and verification to QA/Reviewer when useful.
4. Flag scope creep and change-order triggers early.
5. Do not deploy or change customer systems without approval.
