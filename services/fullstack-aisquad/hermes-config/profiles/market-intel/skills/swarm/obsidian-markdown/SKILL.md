# Obsidian Markdown

## Procedure
1. Preserve existing frontmatter, headings, links, and task syntax.
2. Use clear headings and source links.
3. Prefer small edits over reshaping a vault structure.
4. Do not bulk rename, delete, or reorganize notes without greenlight.
