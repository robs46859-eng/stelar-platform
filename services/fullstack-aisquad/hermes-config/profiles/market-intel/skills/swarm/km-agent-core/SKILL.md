# KM Agent Core

## Procedure
1. Identify the source of record before editing durable knowledge.
2. Keep operational memory concise, dated, and source-linked.
3. Prefer append/update over broad rewrites.
4. Flag contradictions and stale claims for human review.
5. Do not purge, bulk-edit, or change source-of-record structure without greenlight.
