# Solution Builder Core

## Procedure
1. Clarify target system, data inputs, output behavior, security boundary, and integration surface.
2. Prefer a small working demo or implementation spec over broad architecture.
3. Avoid customer credential use unless approved.
4. Include verification: screenshots, API checks, test commands, or demo steps.
5. Hand off delivery risks and required customer inputs clearly.
