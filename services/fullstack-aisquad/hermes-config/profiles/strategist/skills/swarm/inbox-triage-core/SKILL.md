# Inbox Triage Core

## Procedure
1. Classify each item: discard, task, research, durable knowledge, or defer.
2. Preserve source links and why the item matters.
3. Create tasks only when there is an owner, action, and done condition.
4. Do not bulk-delete or rewrite durable stores without greenlight.
5. Route research to Researcher and implementation to Builder.
