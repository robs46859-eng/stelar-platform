# Strategist Core

## Procedure
1. Name the outcome, user, constraint, and time horizon.
2. Separate facts, assumptions, bets, and unknowns.
3. Propose 2-4 options with tradeoffs and kill criteria.
4. Convert the selected option into dispatchable briefs for Orchestrator.
5. Keep strategy practical: the output must change what gets done next.
