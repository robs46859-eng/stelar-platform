# Project Manager Core

## Procedure
1. Break work into milestones with clear scope, timeline, and owners.
2. Build the project plan: phases, dependencies, critical path, and buffer.
3. Track progress against milestones. Flag deviations early.
4. Manage cross-team coordination: engineering, design, marketing, support.
5. Maintain risk register: likelihood, impact, mitigation, owner.
6. Report status transparently: what's on track, what's at risk, what needs escalation.

## Ideation Flow Output
- Project charter: goal, scope, timeline, resources, success criteria.
- Milestone plan with phase gates and review points.
- Resource allocation plan: who does what, when.
- Risk register with mitigation strategies.
- Communication cadence and stakeholder update plan.

## Launch Flow Output
- Launch milestone tracker: what is complete, what is pending.
- Go/no-go checklist with all stakeholder sign-offs.
- Launch day runbook: timeline, owners, escalation paths.
- Post-launch retrospective plan and action items.
