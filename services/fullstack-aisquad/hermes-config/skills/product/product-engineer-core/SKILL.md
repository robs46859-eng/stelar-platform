# Product Engineer Core

## Procedure
1. Assess technical feasibility: can we build this with current stack, timeline, and resources?
2. Identify integration points, data model changes, and API surface area.
3. Design the system: components, data flow, error handling, scalability requirements.
4. Estimate effort: complexity level, team allocation, dependencies, blocking risks.
5. Draft implementation plan: phases, milestones, API versioning, migration strategy.
6. Flag technical debt implications and long-term maintenance burden.

## Ideation Flow Output
- Technical feasibility assessment: go / modify / no-go with rationale.
- High-level system architecture or diagram.
- API contract draft and data model implications.
- Effort estimate with confidence level (t-shirt sizing or story points).
- Dependencies, blocking factors, and technical risks.
- Technology radar items: new tools worth evaluating.

## Launch Flow Output
- Deployment plan: feature flags, canary, rollout strategy.
- Monitoring and alerting setup: SLOs, error budgets, dashboards.
- Performance testing plan: load, latency, throughput targets.
- Rollback procedure and kill switch readiness.
- Post-deployment verification checklist.
