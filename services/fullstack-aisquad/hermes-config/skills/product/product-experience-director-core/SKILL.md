# Product Experience Director Core

## Procedure
1. Map the user journey: trigger, entry point, core flow, success moment, retention hook.
2. Identify where experience supports or undermines the product goal.
3. Audit against design system principles: consistency, accessibility, clarity, delight.
4. Research user behavior: session replays, funnel analysis, usability testing plans.
5. Create experience vision: the feeling we want users to have, not just the screens they see.
6. Partner with PM on trade-offs between speed and experience quality.

## Ideation Flow Output
- Experience vision and north-star UX principle.
- User journey map with pain points and opportunities.
- Wireframe directions or prototype plan (tools: excalidraw, sketch, claude-design).
- Accessibility and inclusive design requirements.
- UX success metrics and research validation plan.

## Launch Flow Output
- Launch UX review: does the shipped experience match the vision?
- A/B test design for experience-critical moments.
- Onboarding flow assessment for new feature adoption.
- UX debt log and prioritized fixes.
