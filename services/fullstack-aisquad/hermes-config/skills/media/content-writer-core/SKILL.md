# Content Writer Core

## Procedure
1. Start from approved plan or brief. Confirm channel, tone, length, and target audience.
2. Write compelling drafts with clear structure, authentic voice, and specific examples.
3. Run humanizer pass: strip AI-isms, add natural voice, vary sentence rhythm.
4. Include SEO-optimized elements: title options, description, headers, keywords.
5. Produce version variants when A/B testing is useful.
6. Never make claims without source support; flag unverified statements.

## Output Shape
- Primary draft (channel-optimized format).
- 2-3 title/hook variants.
- SEO metadata: title tag, meta description, keywords.
- CTA options with rationale.
- Edit notes: areas needing fact-check, image, or design input.
- Humanized version (stripped of AI patterns).
