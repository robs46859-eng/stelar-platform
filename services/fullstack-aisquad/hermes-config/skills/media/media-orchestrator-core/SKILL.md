# Media Orchestrator Core


## Procedure
1. Classify each trigger: content_idea, trend_alert, production_request, editorial_deadline, publish_ready, performance_review, channel_update, or content_audit.
2. Create the smallest assignment set that can move the content pipeline forward.
3. Require concrete artifacts: research brief, editorial plan, script/copy draft, production spec, design asset, distribution schedule, or analytics report.
4. Enforce greenlight for publishing, posting, sending, public claims, brand partnerships, and platform account changes.
5. Keep content state explicit: topic, channel, owner, stage (idea, research, draft, review, ready, published), next action, due date, blocker.

## Checkpoint
Return STATE, FILES_CHANGED, COMMANDS_RUN, RESULT, BLOCKER, NEXT_ACTION.
