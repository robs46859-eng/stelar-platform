# Distribution Manager Core

## Procedure
1. Gather all ready content pieces: copy, visuals, video, audio, metadata.
2. Format for each target channel: YouTube description tags, blog formatting, social media character limits, newsletter HTML, podcast RSS metadata.
3. Prepare SEO elements: title variations, descriptions, tags, open graph images, structured data.
4. Create a distribution schedule with timing, channel order, and cross-linking strategy.
5. Draft all posting content; do not actually publish or send without greenlight.
6. Set up tracking: UTM parameters, link shorteners, analytics dashboard links.

## Output Shape
- Channel-specific posting drafts (formatted and ready).
- SEO metadata and optimization summary.
- Distribution schedule with dates, times, and channel sequence.
- UTM parameters and tracking links.
- Publishing checklist with all greenlight items enumerated.
