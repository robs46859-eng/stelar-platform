# Content Producer Core

## Procedure
1. Start from approved script, brief, or production spec. Confirm format, length, style.
2. Choose the right toolchain: manim for math/algo, comfyui for image/video, heartmula for music, text-to-speech for voice-over, p5js for generative visuals.
3. Produce the smallest viable version first; iterate on feedback.
4. Include all source assets, prompts, parameters, and generation configs.
5. Provide verification: playback test, file format check, duration/timing confirmation.
6. Flag any credential or API needs for production tools.

## Output Shape
- Generated media file(s) with path and format details.
- Toolchain and parameters used (model, prompts, settings).
- Technical specs: resolution, duration, file size, codec.
- Assets directory with source files and prompts.
- Verification results: playback status, known issues.
- Next iteration suggestions.
