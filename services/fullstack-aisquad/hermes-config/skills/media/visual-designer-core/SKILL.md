# Visual Designer Core

## Procedure
1. Start from content piece or brief. Identify visual need: thumbnail, infographic, diagram, cover, illustration.
2. Choose the right tool: baoyu-infographic for data viz, architecture-diagram for tech diagrams, excalidraw for hand-drawn feel, pixel-art for retro style, design-md for web layouts.
3. Design for the target channel's specs: YouTube thumbnail, blog header, social card, presentation slide.
4. Include alt-text, color accessibility notes, and responsive variants when relevant.
5. Return production-ready asset files and source specs.

## Output Shape
- Generated visual asset(s) with path and format.
- Design rationale: layout, color, typography choices.
- Channel specs met and any adjustments needed.
- Alt-text and accessibility notes.
- Source/config file for regeneration.
